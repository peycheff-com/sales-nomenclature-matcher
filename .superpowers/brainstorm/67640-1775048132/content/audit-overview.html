UI Audit Overview

Issues found across 11 pages, organized by pattern category

Phase 1: Shared Patterns to Fix

CRITICAL

Loading States

Currently mixing: spinner, animate-pulse text, "—" dashes, no indicator. Need unified skeleton loader component + standardized spinner usage.

Affects: All 11 pages
CRITICAL

Empty States

EmptyState component exists but used inconsistently. Some pages show wrong messages, others show nothing. Need correct empty state for every data view.

Affects: Dashboard, Requests, Catalog, Suppliers, Admin
HIGH

Error Handling

Mix of toast, inline, and modal errors with no clear pattern. Need: toasts for transient, inline for form fields, full-page for fatal errors.

Affects: All pages with forms/API calls
HIGH

Responsive Layout

Settings sticky bar uses hardcoded left-64. Tables overflow on mobile. Supplier selector cramped. Need responsive fixes in layout + per-page.

Affects: Settings, Catalog, Suppliers, Dashboard
MEDIUM

Accessibility

Missing aria-labels on icon buttons, no role="status" on spinners, color-only status indicators, no keyboard hints on modals.

Affects: All pages
MEDIUM

Dialogs & Confirmations

Dashboard uses window.confirm() instead of AlertDialog. Delete confirmations don't show item names. Dialog forms don't reset on reopen.

Affects: Dashboard, Users, Suppliers, Catalog

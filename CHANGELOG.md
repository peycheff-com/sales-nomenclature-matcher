### Added / Добавлено

- MIT open-source license and contributor-facing governance documents.
- Bilingual English/Russian project, testing, production, and open-source
  readiness documentation.
- Backend 100% coverage gate and frontend Vitest coverage gate.
- Production readiness checker for release and deployment reviews.

- MIT license и документы для open-source управления проектом.
- Двуязычная English/Russian документация по проекту, тестированию,
  production и open-source readiness.
- Backend coverage gate на 100% и frontend Vitest coverage gate.
- Production readiness checker для release и deployment review.

### Changed / Изменено

- Default documentation now describes the free/local-first deployment path.
- CI includes frontend coverage, frontend dependency audit, backend coverage,
  production readiness checks, and production-compose smoke tests.

- Документация по умолчанию описывает free/local-first deployment path.
- CI включает frontend coverage, frontend dependency audit, backend coverage,
  production readiness checks и production-compose smoke tests.
